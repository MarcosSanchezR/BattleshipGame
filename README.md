# IWSIM22-03 BATTLESHIP
## Overview

This project was developed collaboratively as part of the Software Engineering Fundamentals course during the third year of degree studies at Universidad Politécnica de Madrid (UPM). It covers the essential stages of the software development lifecycle, emphasizing solid architectural planning, clean code practices, and automated verification.

The application is structured around a three-layer architecture adhering to the Model-View-Controller (MVC) architectural pattern to ensure a clear separation of concerns, high modularity, and maintainability. Prior to implementation, the domain models and system workflows were formally specified using UML diagrams. The core functionality was built in Java applying object-oriented design principles and thoroughly validated through a comprehensive suite of automated unit tests in JUnit.

## Feature

The application incorporates a user authentication system that manages account registration, credential verification, and user sessions. At its core, it features an interactive gameplay engine responsible for managing dynamic game states, enforcing game mechanics, and handling player interactions within the decoupled architecture.

To support maintainable and modular code, the system leverages creational design patterns—specifically Singleton for centralized resource coordination and Factory for flexible object instantiation. Reliability and functional integrity across all these components are ensured through a comprehensive suite of automated unit tests developed with JUnit.

### Tech Stack
- **Language**: Java.
- **Build Tool**: Maven.
